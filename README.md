# Mi portafolio personal

Portafolio hecho con Vite + React + TypeScript.

## Cómo iniciarlo

1. `npm install`
2. `npm run dev`
3. Abrir http://localhost:5173

## Qué construí

- Componente `Presentacion`: muestra nombre y descripción.
- Componente `ListaTecnologias`: recibe una lista por props y la muestra con `map`.
- Componente `ListaProyectos`: muestra la tarjeta del proyecto Fila creativa.
- Estilos con CSS: colores, degradado, efectos al pasar el mouse, diseño para pantalla angosta y ancha, y un botón de modo oscuro hecho con `useState`.
